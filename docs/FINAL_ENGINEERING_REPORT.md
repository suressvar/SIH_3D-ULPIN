# Astra VI — final engineering audit

Verified locally on 14 September 2026. This report supersedes the limitations resolved since the phase 1–4 reports. **Proposed 3D ULPIN** is an Astra extension, not an official government standard. Prototype acceptance has no legal title effect.

## Outcome

The prototype connects stored parcels and vertical geometry to evidence, calculated validation, deterministic identities, separate officer review, immutable history and Cesium visualization. The final audit preserved the existing stack and working modules. It fixed an actual empty-root 3D Tiles traversal defect, connected tile streaming, bounded history reads, removed repeated per-change/per-suggestion queries, corrected stale model downloads, added request deadlines and automatic rendering fallbacks, and created a named judge property.

This is a locally verified prototype, not a production deployment or a photogrammetric reconstruction. Live cloud authentication, real Redis delivery on this machine, and trained AI inference are not verified.

## PROTOTYPE FALLBACK

- The guarded browser-test host verifies real signed JWTs against its local JWKS and actual DB membership. It replaces Redis transport with a background dispatcher executing the real worker, and bypasses rate limiting only in that test host. It requires `ENVIRONMENT=test`, `ASTRA_UI_TEST=1` and the dedicated `astra_ui_test` database. It is not a normal deployment login mode.
- Local private filesystem storage substitutes for cloud object storage in development.
- Real source polygons/prisms are used where current geometry has no matching generated asset. Stale files are not represented as the current geometry; model downloads are disabled until regeneration.
- The no-WebGL view is SVG source geometry. MapLibre itself requires WebGL, so it cannot alone solve complete WebGL absence.
- Rectangular volume fixtures demonstrate vertical cadastre. The reference redesign adds a separately labelled illustrative synthetic exterior (windows, balconies, trees and context) generated with Blender. It is not surveyed architecture or a scan, and does not change recorded cadastral geometry. See REFERENCE_REDESIGN.md.
